## 执行规则

1. 每完成一项优化，coder agent 必须把对应复选框从 `- [ ]` 改为 `- [x]`。
2. 打勾前必须完成实现、必要测试和结果说明；不能只改代码不验证。
3. 如果某项无法完成，不能打勾；在该项下追加 `阻塞原因：...` 和下一步建议。
4. 每项优化只允许改动与该项直接相关的文件；不要把无关重构混入同一次完成记录。
5. P0 未完成前，不新增非主链路功能。
