# 模型地址提示卡片移除设计

## 目标

从管理端“编辑模型”弹窗中移除“继承账号地址 / 模型覆盖地址”提示卡片，以及“改回继承账号地址”操作，避免界面继续表达已经不需要管理员处理的账户地址继承关系。

## 变更范围

- 删除模型账户选择器下方的地址状态卡片。
- 删除地址继承、覆盖值比较和清空模型 `baseUrl` 的局部 UI 逻辑。
- 保留绑定账户选择、账户凭据状态、账户探活提示和新模型默认启停逻辑。
- 不修改 Backend API、数据库结构、模型保存载荷或运行时凭据解析。
- 不迁移、不清空已有模型记录中的 `baseUrl`，防止 UI 删除产生隐式数据变更。

## 交互结果

管理员选择模型绑定账户后，只看到该账户的厂商、凭据和健康状态。弹窗不再展示地址来源、最终生效地址、Endpoint 继承信息，也不再提供清空模型地址的快捷操作。

## 测试

- 增加或调整管理端静态契约测试，确认已删除相关文案和清空 `baseUrl` 的按钮处理。
- 运行管理端相关测试、类型检查和生产构建。
- 验证编辑既有模型时，账户绑定与其他模型字段仍可正常保存。

## 非目标

- 本次不删除模型 DTO 中的 `baseUrl` 字段。
- 本次不改变账户与模型的后端凭据解析规则。
- 本次不处理历史模型地址数据。
