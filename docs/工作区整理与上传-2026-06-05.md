## Worker：oFox 参考图（`/images/edits`）

### 问题与根因

带参考图的 `openai_images` 任务会走 `POST /images/edits`（multipart）。网关返回 `You must provide a model parameter` 时，body 里其实已有 `model=openai/gpt-image-2`。

根因：`requests.Session` 默认带了 `Content-Type: application/json`，multipart 请求未被覆盖为 `multipart/form-data`，oFox 按 JSON 解析导致表单字段（含 `model`）被忽略。

### 修复要点

- Session 默认头 **不再** 设置 `Content-Type`；文生图仍用 `json=`，由 requests 自动加 `application/json`。
- 参考图编辑使用 `_multipart_headers()`，只传 `Authorization` 与 `Connection`。
- 参考图 URL / 本地 `/generated/...` / base64 → `worker/utils/input_image.py` 解析为 data URL 后 multipart 上传。
- oFox 约定：`model=openai/gpt-image-2`、`size=auto`、`quality=low`；可选 `extraAuthJson`：`editModel`、`preferSdkEdit`、`proxyUrl`、`trustEnv`、`sslEofRetries`。
- 文档：[oFox Images API](https://ofox.ai/zh/docs/api/openai/images)
