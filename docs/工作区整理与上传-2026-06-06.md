# 工作区整理与上传（2026-06-06）

## 本次上传范围

在已合并 `origin/dev` 的基础上，整理 **音乐生成（Suno）**、**模型供应商元数据**、**工具字段 UI 分层**、**社区音频展示** 与 **工作台能力控件** 等改动，并上传对应文档。

| 类别 | 策略 |
| --- | --- |
| 不上传 | `.env` 及本地密钥 |
| 不上传 | `data/generated-media/`、`data/exported-generated-media/`、`backend/data/agent-files/**` |
| 上传 | `backend`、`worker`、`user-web`、`admin-frontend`、`sql/`、`docs/` |

## 分支基线

- 本地 `feature/admin-web` 已快进合并 `origin/dev`（含支付宝收银台修复、充值链路、部署脚本等）。
- 本次提交为合并后的增量功能与文档整理。

## Backend

### 模型供应商元数据

- 新增表 `model_provider_metadata`（`DataInitializer` + `schema-test.sql` 同步）。
- `ModelProviderMetadataService`、`ModelExecutionSnapshotService`：统一读取供应商能力、协议、Worker 就绪状态。
- `ModelProviderAdapter` 接口：为后续按供应商拆分连通性测试预留扩展点。
- `ExecutionContextResponse` / `ExecutionModelConfigResponse` 下发执行快照，Worker 可按 provider 校验能力。

### 音乐生成工具类型

- `ToolType.MUSIC_GENERATION`、`ExecutionHandler.MUSIC_GENERATION`。
- `ToolTemplateBootstrap` 种子模板 `music_generation_default`（Suno 参数字段）。
- `model-providers.yml` 补充 Suno 相关供应商定义。

### 社区

- `community_posts.media_url`（`sql/047_community_post_media_url.sql`）。
- 列表/详情返回音频类同款作品的媒体地址。

### 其它

- 任务创建与算力派发链路适配新工具类型；`FileReadingPolicy` 扩展用户上传读取策略。

## Worker

- `client/suno_music_client.py`：Suno API 创建任务、轮询、曲目解析、参考音频上传。
- `handlers/music_generation_handler.py`：消费 `MUSIC_GENERATION` 任务，落盘音频并回写结果。
- `generated_audio_persister.py`、`task_handler_router.py`、`providers/registry.py` 注册与持久化。
- 配置项：`worker/config.py`（如 `SUNO_CALLBACK_URL`、`SUNO_MUSIC_MODEL`）。

## User Web

- `pages/Dashboard/Page.vue`：工作台能力选择与任务流增强（与 `CapabilityControls` 联动）。
- `pages/Chat/CapabilityControls.vue`：按模态/能力展示可选工具与参数入口。
- `components/DynamicForm/DynamicForm.vue` + `utils/fieldUiMeta.ts`：字段 `uiTier` / `uiGroup` / `visibleWhen` 分层展示。
- `ResultRenderer`、`taskResultBlocks`、`AssetCard`：支持音频结果块与预览。
- 社区：`CommunityGallery`、`CommunityPost/Page`、`CommunityAudioMedia.vue` 展示音频同款。

## Admin Frontend

- `field-schema-editor.tsx`：字段 schema 编辑与 UI 元数据（`field-ui-meta.ts`）。
- `tool-user-preview-card.tsx` + `tool-user-preview.ts`：管理端预览用户侧表单效果。
- `unified-api-settings.tsx`、`tools/page.tsx`：统一 API 与工具页配合新供应商元数据。
- `lib/tool-fields.ts`：Suno 专用字段类型（`suno_model`、`suno_create_mode` 等）。
