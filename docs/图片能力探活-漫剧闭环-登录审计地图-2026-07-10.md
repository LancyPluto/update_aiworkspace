# 图片能力探活、AI 漫剧闭环与登录审计地图

日期：2026-07-10

## 目标

本轮补齐三个生产问题的最小闭环：

1. 管理端模型测试要区分“账户网关可达”和“具体模型能力可用”，避免账户显示连通但用户任务实际失败。
2. AI 漫剧工作流最终产物要能结构化写入视频结果，并被社区自动发布识别为视频作品。
3. 登录/注册审计要能进入 Grafana 地球地图，支持查看来源地、失败 IP、管理端失败登录和认证趋势。

## 账户 2 与 gpt-image-2 失败原因

生产任务 `T2026071085496FFBD0` 使用的是 `gpt_image2`，模型配置绑定账户 2，网关地址为 `https://sub2api.wlcloudai.com/v1`。

账户探活成功只说明 `/models` 或网关入口能访问，不能证明图片生成接口有权限。该任务真实执行时请求 `/v1/images/generations`，上游返回：

```json
{"error":{"message":"Image generation is not enabled for this group","type":"permission_error"}}
```

结论：绑定关系和 baseUrl/key 不是主要问题，账户所属 group 没开图片生成能力。修复措施是在模型行“测试连接”里增加图片生成接口 dry-run：先验证 `/models` 中有模型名，再用不带 prompt 的请求触达 `/images/generations`。正常 4xx 参数校验表示接口可达；401/403 或图片能力未开通文案会提前显示为模型测试失败。

## AI 漫剧最小闭环

工作流根任务成功时不再固定写 `MARKDOWN`。如果编排结果里存在 `finalVideoUrl` 或 `videoUrl`，后端会写入结构化 `VIDEO` JSON：

```json
{
  "resourceType": "VIDEO",
  "finalVideoUrl": "/generated/workflow/final.mp4",
  "videoUrl": "/generated/workflow/final.mp4",
  "coverUrl": "/generated/workflow/cover.jpg",
  "subtitleUrl": "/generated/workflow/subtitle.srt",
  "segments": [],
  "sceneCount": 0,
  "markdown": "..."
}
```

社区自动发布会从该 JSON 中提取视频地址和封面地址，生成 `VIDEO` 类型作品。没有视频地址时仍保留旧的 Markdown 结果行为。

## 登录/注册审计与 Grafana 地图

后端新增 `auth_security_events` 表，记录：

- 事件类型：登录、注册、短信验证码、短信登录/注册、重置密码、管理员登录。
- 结果：成功或失败。
- 失败原因、用户类型、userId。
- 账号脱敏值和 SHA-256 hash，不保存明文手机号。
- IP、User-Agent、traceId。
- GeoIP 解析出的国家、地区、城市、经纬度。

Prometheus 只记录低基数指标：

```text
auth_security_events_total{event_type,result,method,user_type,reason}
```

Grafana 地球地图使用 MySQL datasource 查询 `auth_security_events.latitude/longitude` 聚合点位，不把 IP 或经纬度放进 Prometheus label。

## 部署要求

Grafana 需要加载三个 datasource：

- `Prometheus`
- `Loki`
- `MySQL-Auth-Audit`

生产建议创建 MySQL 只读账号给 Grafana 使用，并在 `deploy/.env` 或部署环境中设置：

```dotenv
GRAFANA_MYSQL_HOST=mysql:3306
GRAFANA_MYSQL_DATABASE=ai_supermarket_v1
GRAFANA_MYSQL_USER=grafana_readonly
GRAFANA_MYSQL_PASSWORD=replace-with-readonly-password
```

登录来源地图需要 GeoIP 数据库文件。默认容器路径：

```text
/data/geoip/GeoLite2-City.mmdb
```

部署侧需把宿主机 `data/geoip` 挂载到 backend 容器，并设置：

```dotenv
AUTH_GEOIP_DATABASE_PATH=/data/geoip/GeoLite2-City.mmdb
```

如果未放置 mmdb 文件，审计记录和趋势仍正常，地图点位会为空。

账号聚合字段使用 HMAC-SHA256。生产建议显式设置：

```dotenv
AUTH_SECURITY_AUDIT_HASH_PEPPER=replace-with-long-random-secret
```

未设置时会回退使用 `JWT_SECRET`，避免手机号 hash 被简单离线枚举。

## 验收标准

1. 管理端模型行测试 `gpt-image-2` 时，如果账户未开图片生成能力，返回明确失败文案，不再只显示 JSON 解析错误。
2. `Image generation is not enabled for this group` 在 Worker 侧分类为 `MODEL_CAPABILITY_DISABLED`，任务失败提示为“模型账户未开通当前模型能力”。
3. 漫剧工作流产生 `finalVideoUrl` 后，根任务结果类型为 `VIDEO`，社区自动发布的作品 `media_url` 指向最终视频。
4. 用户登录成功和失败后，`auth_security_events` 均有记录，手机号不以明文形式写入 `account_masked`。
5. Grafana 中出现 `MySQL-Auth-Audit` datasource 和“登录注册审计地球地图”dashboard。
6. 配置 GeoIP 数据库后，地图面板能展示登录/注册来源点位；未配置时，TOP 失败 IP、最近认证事件和 Prometheus 趋势仍能显示。

## 回滚方式

1. 后端可将 `AUTH_SECURITY_AUDIT_ENABLED=false` 临时关闭认证审计落库。
2. Grafana datasource/dashboard 属于 provisioning 配置，删除对应 YAML/JSON 并重建 Grafana 即可移除。
3. 模型测试 dry-run 只影响管理端测试连接，不改变真实任务执行链路；如需回退，恢复 `AgentModelConfigServiceImpl` 的模型测试逻辑即可。
