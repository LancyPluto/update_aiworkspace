# 可灵参考列表表单配置说明

> 适用范围：`kling-multi-image-to-video`、`kling-omni-video` 等需要 `imageList` / `videoList` / `elementList` 的可灵视频工具。  
> 关联文档：[后台工具 JSON 配置说明](./后台工具JSON配置说明.md)、[可灵模型配置.md](../可灵模型配置.md)、[配置包导入导出 — 维护指南](./配置包导入导出-维护指南.md)。

## 1. 背景

早期配置将三个参考列表字段 lazy 配成 `textarea`，placeholder 写「JSON 数组」，用户需手填结构化数据，且 Worker 收到的是 JSON **字符串**而非已解析数组，存在兼容风险。

**正确做法**：使用专用 `fieldType`，由用户端上传/列表编辑器生成 array/object，Worker 再映射为 Kling API 的 `image_list` / `video_list` / `element_list`。

## 2. 字段与控件对照

| fieldKey | 展示名 | fieldType | 提交值类型 | 适用工具 |
| --- | --- | --- | --- | --- |
| `imageList` | 参考图片列表 | `multi_image` | `string[]` | 多图参考生视频、Omni 视频 |
| `videoList` | 参考视频列表 | `multi_video` | `string[]` | Omni 视频 |
| `elementList` | 主体参考列表 | `subject_element_list` | `object[]` | 多图参考生视频、Omni 视频 |

**禁止**：对上述字段使用 `textarea` + JSON placeholder。

## 3. 推荐 optionsJson

### 3.1 imageList（multi_image）

```json
{
  "minCount": 1,
  "maxCount": 7,
  "accept": "image/*",
  "libraryEnabled": true,
  "libraryKind": "image",
  "uiTier": "advanced"
}
```

- `kling-multi-image-to-video`：`required: true`，`minCount: 1`
- `kling-omni-video`：`required: false`

### 3.2 videoList（multi_video）

```json
{
  "maxCount": 4,
  "accept": "video/*",
  "libraryEnabled": true,
  "libraryKind": "video",
  "uiTier": "advanced"
}
```

### 3.3 elementList（subject_element_list）

```json
{
  "maxCount": 7,
  "libraryEnabled": true,
  "uiTier": "advanced"
}
```

用户端支持三种主体模式（可混用）：

| 模式 | 用户操作 | 提交对象 |
| --- | --- | --- |
| 已有主体 ID | 填写 `element_id` | `{"element_id": "123456"}` |
| 图片主体 | 上传正面图 + 1~4 张参考图 | `{"frontal_image": "url", "refer_images": ["url1"]}` |
| 视频主体 | 上传 1 个参考视频 | `{"refer_videos": ["url"]}` |

## 4. 提交与 Worker 映射

```mermaid
flowchart LR
  UI["用户端控件"]
  Params["params.imageList / videoList / elementList"]
  Worker["KlingVideoClient"]
  API["Kling API payload"]

  UI --> Params --> Worker --> API
```

| 表单 fieldKey | Worker params | Kling API |
| --- | --- | --- |
| `imageList` | `imageList` 或 `image_list` | `image_list` |
| `videoList` | `videoList` 或 `video_list` | `video_list` |
| `elementList` | `elementList` 或 `element_list` | `element_list` |

提交示例：

```json
{
  "prompt": "镜头描述…",
  "imageList": ["https://.../ref1.png", "https://.../ref2.png"],
  "videoList": ["https://.../ref.mp4"],
  "elementList": [
    { "element_id": "123456" },
    { "frontal_image": "https://.../front.jpg", "refer_images": ["https://.../side.jpg"] },
    { "refer_videos": ["https://.../clip.mp4"] }
  ]
}
```

Worker 实现要点（`worker/client/kling_video_client.py`）：

- `_encode_media_list`：接受 `string[]` 或 `{image_url}` 对象数组；兼容 JSON 字符串兜底
- `_encode_video_list`：接受 URL 字符串数组或 `{video_url}` 对象数组
- `element_list`：原样透传对象数组

## 5. 管理端配置

### 5.1 字段类型选项

管理端「工具字段编辑器」可选：

- **多参考图** → `multi_image`
- **多参考视频** → `multi_video`
- **主体参考列表** → `subject_element_list`

可视化编辑器可配置：`minCount`、`maxCount`、`libraryEnabled`、`libraryKind`（见 `admin-frontend/components/admin/field-schema-editor.tsx`）。

### 5.2 配置包维护

权威来源：

- 配置包：`ai-tool-market-config-2026-06-15.json`
- 生成脚本：`scripts/patch_kling_config_bundle.py`

更新可灵工具字段后执行：

```bash
python scripts/patch_kling_config_bundle.py
```

再在管理端导入配置包，或部署脚本 `deploy/scripts/import_config_bundle.py`。

## 8. 常见问题

**Q：能否继续用 textarea 手填 JSON？**  
A：不推荐。Worker 虽有 JSON 字符串兜底，但用户体验差且易出错。请迁移为上述 fieldType。

**Q：imageList 能否提交 `[{"image_url":"..."}]`？**  
A：可以。推荐 `multi_image` 提交 `string[]`；若需首/尾帧 `type` 字段，可后续在 `optionsJson` 扩展 `itemExtras`（见 [后台工具 JSON 配置说明](./后台工具JSON配置说明.md) 可灵小节）。

**Q：Agent 如何理解这些字段？**  
A：`AgentToolDescriptorServiceImpl` 将 `multi_image` / `multi_video` 映射为 `array of string`，`subject_element_list` 映射为 `array of object`。
