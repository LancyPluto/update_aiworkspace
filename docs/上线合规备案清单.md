# AI Tool Market 上线资质与备案流程清单

> 更新日期：2026-05-13  
> 适用场景：中国大陆面向公众上线 Web / API / AI 生成式服务。  
> 说明：周期会受省市主管部门、云厂商、材料完整度、业务模式影响，以下为常见排期建议，不构成法律意见。

## 二、建议办理顺序

1. 企业主体、域名、云账号企业认证。
2. ICP 备案。
3. 短信资质、短信签名、验证码模板。
4. 公安联网备案。
5. 生成式 AI 应用登记。
6. 隐私政策、用户协议、AI 生成内容声明、投诉举报入口、内容安全机制。
7. 如果收费，补 ICP 许可证。
8. 如果做平台交易或第三方商家入驻，评估 EDI 许可证。
9. 如果做 App、小程序或快应用，补 APP 备案。
10. 用户量上来或正式投产，做等保定级备案/测评。

## 三、按当前系统的实际判断

如果先做 Web 版、国内服务器、手机号注册、调用国内已备案大模型、暂不收费：

- 必做：企业主体、域名实名、ICP备案、短信资质、公安联网备案、隐私政策/用户协议、内容安全机制。
- 高概率要做：生成式 AI 应用登记。
- 暂可后置：ICP 许可证、EDI 许可证、APP 备案。
- 建议同步准备：等保二级自评/备案路线。

如果一开始就做充值算力、会员付费或 AI 工具超市收费：

- 需要提前评估 ICP 许可证。
- 如果存在第三方商家入驻、交易撮合、平台内交易闭环，还需要评估 EDI 许可证。
- 整体上线时间建议按 2-3 个月以上规划。

## 四、最容易拖周期的事项

- ICP/EDI 许可证：材料要求高，审批周期长。
- 生成式 AI 应用登记：各地口径和材料要求可能不同。
- 短信签名/模板：签名主体、产品名称、备案域名、营业执照主体不一致时容易被驳回。
- 内容安全机制：如果没有输入/输出审核、举报入口、日志留存、人工复核策略，AI 应用登记和平台审核都可能受影响。

## 五、建议的低风险上线策略

优先采用以下策略降低资质复杂度：

- 先上 Web，不先上 App。
- 先用国内服务器和国内已备案模型。
- 先不接境外模型 API。
- 先不做公开社区、内容广场、用户公开发布。
- 先不做第三方商家入驻和交易撮合。
- 付费能力等 ICP 许可证路径确认后再上线。
