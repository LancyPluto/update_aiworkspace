## 5. 计费与对账建议（项目侧）

1. **token 计费 vs 按秒计费混搭**：
   - 视频 2.0 是 token 计费，1.5 Pro 是按秒计费，**`pricing_engine` 里需要把两套规则各建一条 `pricing_rule`**。
   - 我们当前 `modelConfigs` 里 1.5 Pro 的 `unitPrice = 0.875`（取最常用 720P 有声 5s 估算 1.75 ÷ 2），仅为基线，实际按 `pricing_rules` 的「分辨率 × 时长 × audio」三维倍率展开。
2. **结果 URL 24h 必须落库**：图像同步返回的 URL 同样有过期问题，建议生成后立即 `mark_success` 前下载到 OSS。
3. **接入 token 用量回传**：Seedance 2.0 是 token 计费，调用响应里会返回 `usage.tokens` 字段（参考 OpenAI 兼容口径），落到 `billing_usage_logs.charged_credits` 里做精确对账。
4. **新用户赠送额度**：Seedance 2.0 注册赠送 5M tokens（≈ 16 段 15s 视频），算力可观，建议放到「试用渠道」给开发同学用。
5. **多 region**：方舟同时提供北京 / 上海 / 香港 endpoint，国内默认走 `ark.cn-beijing.volces.com`；如果对海外延迟敏感可在 Account 级别加一条香港 vendorAccount。

> **价格快照时间**：2026-06-15。火山方舟阶梯/促销价随时变动，写入 SQL `pricing_rules` 时需带 `effective_at` 字段或在 `extraAuthJson.pricingVerifiedAt` 标注核对日期。
