# 黄金链路验收记录（2026-07-07）

本文用于本轮“核心业务可验收、可灰度、可预期上线”收口。范围只包含 5 条黄金链路与非安全 P0 `P0-TASK-08`；安全出库、密钥轮换和 PPT `toolCode` 收口放到后续阶段。

## 验收基线

| 项目 | 约定 |
| --- | --- |
| 基线分支 | `dev` 或当前合并后的集成分支 |
| 测试账号 | 普通用户 `user1 / 123456`，管理员 `admin / 123456` |
| 任务队列事实源 | 本轮按 RabbitMQ 验收；Redis 仅作为缓存/限流/历史兼容队列代码存在 |
| 本轮不阻断项 | 安全证书/密钥出库、PPT workspace/PPT 导出/PPT `toolCode` |
| 必跑命令 | `backend: mvn test`；`agent-service: pytest -q`；`worker: pytest -q`；`user-web: npm run build`；`admin-frontend: npm run build` |

## 链路 1：文本工具

| 检查点 | 验收记录 |
| --- | --- |
| 基准工具 | 选择线上可用的文本生成工具，优先选固定模型配置且无外部素材依赖的工具 |
| 输入参数 | 一段明确文本需求，例如“为新品咖啡写 3 条小红书种草文案” |
| 任务创建 | 用户端创建任务后，后端生成 `QUEUED` 任务并冻结预计算力 |
| 执行回写 | Worker 进入 `PROCESSING`，成功后回写 `SUCCESS` 与文本结果 |
| 额度 | 成功只扣费一次；重复 success 回调不重复扣费 |
| 前端可见 | 任务结果页或创作流展示文本内容 |
| 自动化覆盖 | `WorkerCallbackIdempotencyTest.repeatedSuccessCallbackDeductsCreditsAndInsertsResultOnce` |

## 链路 2：图片工具

| 检查点 | 验收记录 |
| --- | --- |
| 基准工具 | 选择线上可用的图片生成工具，优先选能稳定返回单图 URL 的工具 |
| 输入参数 | 一段图片提示词，例如“赛博朋克风格的咖啡海报，霓虹灯，产品居中” |
| 任务创建 | 用户端创建任务后，任务进入 `QUEUED/PROCESSING` |
| 媒体回写 | Worker 成功后回写图片 JSON/URL，后端保存结果资源 |
| 额度 | 成功只扣费一次，失败不扣费并释放冻结算力 |
| 前端可见 | 任务结果页、创作流、素材库或社区卡片能展示图片；社区缩略图走派生 URL，data URL 不派生 |
| 自动化覆盖 | `communityPostMedia.test.mjs` 图片派生 URL；后端 success/failure 幂等测试 |

## 链路 3：视频/数字人失败释放

| 检查点 | 验收记录 |
| --- | --- |
| 基准工具 | 选择线上可用的视频或数字人工具，优先选异步轮询 provider |
| 输入参数 | 一段短视频提示词，或数字人口播脚本文案 |
| 任务创建 | 创建任务后冻结预计算力 |
| 失败路径 | 模型失败、轮询超时或 Worker 内部失败时，Worker 必须回写 failed |
| 额度 | failed/timeout 后释放冻结算力；重复 failed 不重复释放 |
| 重试/死信 | 重试后迟到的旧 timeout 回调不能释放新一轮冻结额度；真正第二轮失败只释放第二轮一次 |
| 自动化覆盖 | `WorkerCallbackIdempotencyTest.retryThenLateTimeoutCallbackDoesNotReleaseNewFreezeOrEndQueuedTask`；`test_video_handler_timeout_marks_failed_for_credit_release`；`test_seedance_async_poll_does_not_repeat_create_request` |

## 链路 4：Agent 调工具

| 检查点 | 验收记录 |
| --- | --- |
| 基准工具 | 选择 Agent 可调用的文本或图片工具 |
| 输入参数 | 用自然语言要求 Agent 调用工具，例如“帮我生成一张咖啡海报” |
| 意图识别 | Agent 能识别工具意图；缺参时提示补充或走确认 |
| 任务创建 | Agent 只通过后端桥接创建任务，不直接结算额度 |
| 事件回传 | Agent Run 事件包含 task dispatched、task status、final result |
| 前端可见 | 用户能在 Agent 对话或任务结果中看到产物 |
| 自动化覆盖 | `agent-service/tests/test_tool_orchestrator.py` 与 `test_backend_tool_bridge.py` 中的后端桥接契约 |

## 链路 5：社区同款

| 检查点 | 验收记录 |
| --- | --- |
| 基准作品 | 选择一个已发布且带 `toolCode` 的社区作品 |
| 入口 | 社区详情页或社区卡片点击“同款创作” |
| 预填 | 创建页获得工具、素材、提示词上下文和 `sourcePostId` |
| 任务创建 | 创建任务 payload 带 `sourcePostId` |
| 归因 | 后端记录 `task_created` 社区事件，同款计数/归因可追踪 |
| 额度 | 任务成功按普通任务扣费；失败释放冻结算力 |
| 前端可见 | 同款后的新任务结果可展示，社区媒体缩略图/视频 poster 不白屏 |
| 自动化覆盖 | `communityPostMedia.test.mjs`；用户端社区同款入口相关现有测试 |
