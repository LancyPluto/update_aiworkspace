## 文档维护规则

1. 接口字段变更必须同步 `docs/api/openapi.yml`。
2. 数据库字段变更必须同步 `DataInitializer`、`sql/*.sql` 和 `backend/src/test/resources/schema-test.sql`。
3. 临时开发记录不再长期堆在 `docs` 根目录；若确实需要沉淀，合并进 `近期变更记录.md` 或专题文档。
4. Agent 相关方案必须写清楚是否已落地，避免把探索性蓝图当成当前架构。
