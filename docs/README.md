- `.env`、`WXcert/*.pem`、`_remote.py`、`_fix_remote.py` 已从 Git 索引移除，并由 `.gitignore` 阻止再次入库。
- 生产环境由 `APP_PRODUCTION_MODE=true` 或 `APP_ENV=production` 判定。
- 生产任务队列事实源为 RabbitMQ，Redis 队列仅保留本地开发或兼容模式。
