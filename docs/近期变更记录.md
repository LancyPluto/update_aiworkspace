# 近期变更记录

## 2026-05-20 Agent 消息重新生成（方案 A）

- `agent_messages` 增加 `status`（`ACTIVE`/`SUPERSEDED`）、`superseded_at`；会话列表与内部上下文仅使用 `ACTIVE` 且按 USER 锚点截断历史。
- `agent_runs` 增加 `parent_run_id`、`source_user_message_id`、`client_request_id`（可选幂等键）。
- 新 API：`POST /api/v1/agent/runs/{runId}/regenerate`、`POST /api/v1/agent/sessions/{sessionId}/messages/{messageId}/edit-regenerate`；OpenAPI 增加 `AgentChat` 标签与相关 schema。
- 存量库：`sql/021_agent_message_regenerate.sql`；本地/测试库表结构见 `sql/005_agent_module.sql`、`backend/src/test/resources/schema-test.sql`；启动时 `DataInitializer` 会按需 `ensureColumn` 补列。

## 2026-05-16 多模态工具和按次计费

- 工具增加 `toolType`、`inputModality`、`outputModality`、`configNote`。
- 用户端动态表单支持单选、多选、滑块、图片、文件字段。
- 用户端结果渲染支持文本、JSON、图片、音频、视频和报告。
- 新增 SiliconFlow 图片生成 provider：`siliconflow_images`。
- Worker 增加图片生成 handler，支持图片落盘和稳定 `/generated/images/...` URL。
- 模型计费单位从 1K token 调整为 1M token。
- 新增 `TOKEN_PER_M` 和 `PER_CALL` 计费方式。
- 生图任务按返回图片数量上报 `billableUnits`。
- 修复字段模板重复保存唯一键冲突。
