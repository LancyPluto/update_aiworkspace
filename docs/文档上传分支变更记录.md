# 文档上传分支变更记录

## 2026-05-28

- 用户端素材库和创作工作台增加资产预览弹窗，支持图片、视频、音频和文本结果的沉浸式查看、下载、查看任务记录和继续创作推荐。

- 修复 `AssetPreviewModal.vue` 中的字符串和标签断裂，避免文档/素材预览功能构建失败。
- 管理端配置包导入导出补齐新增字段：模型连接超时、读取超时、工具 `executionHandler`、Agent 工具启停状态。
- Worker 可灵轮询修复：顶层 `message=SUCCEED` 只代表查询接口成功，`task_status=submitted` 会继续轮询，不再误判为生成完成但无 URL。
