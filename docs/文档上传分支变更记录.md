# 文档上传分支变更记录

## 2026-05-29

### 用户端视觉与交互优化

- 将用户端整体视觉继续向 SeaArt 风格收敛：深色模式、玻璃拟态、柔和紫色高光、悬浮输入框和更清爽的资产预览。
- 优化 `AppShell` 顶部栏：搜索框与算力展示解耦，新增独立“剩余算力”胶囊，创建按钮改为更柔和的渐变与阴影。
- 增加用户名显示兜底逻辑：当昵称疑似出现编码乱码时，回退展示用户名或可读前缀。

### 工作台与素材资产

- 工作台与素材库统一使用资产预览弹窗，支持图片、视频、音频和文本结果的沉浸式查看。
- 资产弹窗右侧提供可继续创作的工具推荐，支持将当前资产带入工作台继续生成。
- 工作台历史任务支持模态过滤、下拉动态加载、生成中状态前置展示、失败重试和失败/取消任务删除。
- 工作台创建浮窗、素材选择弹窗、模态浮窗和历史任务卡片已按 SeaArt 风格做轻量化与位置修正。

### Agent 页面

- 移除 Agent 右侧空的“工作区记忆”面板，让对话区获得更完整的可用宽度。
- 优化 Agent 对话 UI：更有呼吸感的气泡、生成中状态、紧凑模型选择器和简洁多媒体结果展示。
- Agent 历史会话增加“今天 / 昨天 / 前 7 天 / 更早”分组，长标题单行省略，删除按钮仅在悬停时显示。
- Agent 输入框禁用浏览器默认拖拽缩放，改为自动撑高并限制最大高度。
- Agent 生成的图片、视频、音频结果点击后接入统一资产卡片，不再暴露后台 `provider/model` 等配置字段。

### 结果解析与详情页

- `/tasks/:id/result` 改为复用统一的 `buildTaskResultBlocks` 结果解析逻辑，避免 Agent 任务和工作台任务展示不一致。
- 修复 Agent 结构化返回内容中完整 JSON 被误当作提示词展示的问题，只提取真实用户输入字段。
- 视频模型效果和任务结果中的媒体 URL 统一归一化，减少本地与线上环境展示差异。

### 验证

- `npm run build` in `user-web`

## 注意事项

- 当前工作区存在若干未纳入本次提交的本地运行产物，例如 `backend/data/agent-files/**` 和 `.env`，这些不应随前端 UI 优化一起提交。
- 分支当前为 `feature/admin-web`，本次提交只包含用户端前端优化与对应文档。
