# Agent 优化与工作区整理（2026-06-04）

## 本次上传范围

本次整理围绕 Agent 主链路、长期记忆、用户端对话体验和后台参数配置展开，排除本地运行产物与敏感配置：

- 不上传 `.env` 本地密钥配置。
- 不上传 `data/generated-media/`、`data/exported-generated-media/` 等生成媒体产物。
- 上传源码、测试、示例配置、优化清单和链路说明文档。

## Agent Service

- 路由逻辑进一步收敛：将会话保护、规则信号和 LLM 路由上下文拆出，减少 `deep_agents_engine.py` 中的残留判断。
- 产品工具调用循环会接收冻结的工作区长期记忆，避免新会话中工具参数丢失用户偏好。
- follow-up 续写提示词改为“当前用户要求优先，上一轮提示词只作风格参考”，避免把旧主体错误拼进新 prompt。
- 记忆整理升级为 LLM 结构化梳理：
  - 只更新专用 `用户画像与偏好摘要`。
  - 不覆盖用户显式写入的 `preference` 等独立记忆。
  - 推断出的新偏好默认进入候选记忆。
  - 过滤临时改图、工具 JSON、图片/视频 URL 和一次性参数。
  - 使用 `metadataJson` 记录整理触发状态，避免超过阈值后每轮重复整理。

## 后台参数

后台 Agent 参数页新增自动记忆梳理触发项：

- `agent.memory.consolidation_llm_enabled`
- `agent.memory.consolidation_token_threshold`
- `agent.memory.consolidation_recent_tool_threshold`
- `agent.memory.consolidation_max_context_messages`
- `agent.memory.consolidation_prompt`

后端同步补齐默认值、run context 下发、恢复默认和长 prompt 版本记录。
