# 反馈优化规则 V1

## 目标

- 当用户对首版结果不满意时，提供可结构化消费的反馈信息。
- 生成下一版时，优先使用当前输入，其次使用当前反馈，最后才参考历史偏好。

## 推荐反馈项

- `moreColloquial`: 更口语化一点
- `lessAdvertising`: 减少广告感
- `highlightSellingPoints`: 更突出核心卖点
- `shorterLength`: 缩短一点
- `retitle`: 换一种标题风格

## Prompt 拼装建议

- 当前输入优先级最高，不能被历史偏好覆盖。
- 当前反馈作为本轮优化指令追加到用户提示词中。
- 历史偏好只在当前输入未明确表达时兜底使用。

## 不建议在 V1 做的事

- 不做无上限历史结果累积。
- 不做自由检索式长期记忆。
- 不让模型自行从历史记录中挑信息使用。
