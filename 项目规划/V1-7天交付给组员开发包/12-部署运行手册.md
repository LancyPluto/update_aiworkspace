# 12. 部署运行手册

本文用于第 7 天交付演示环境。

## 1. 部署组件

```text
MySQL
Redis
后端服务
Python Worker
用户端前端
管理后台前端
```

## 2. 发布顺序

```text
1. 备份数据库
2. 执行数据库脚本
3. 启动/更新后端服务
4. 启动/更新 Worker
5. 构建并发布用户端前端
6. 构建并发布管理后台前端
7. 导入初始化数据
8. 跑最终验收脚本
```

## 3. 启动后检查

```text
后端健康检查通过
Redis 连接正常
Worker 日志显示已启动
管理员能登录
普通用户能登录
后台能发布工具
用户能创建任务
Worker 能回写结果
```

## 4. 初始化数据

```text
管理员：admin / 123456
普通用户：user1 / 123456
测试工具：小红书文案生成
用户初始算力：100
工具消耗算力：10
```

## 5. 回滚方式

V1 演示环境回滚优先级：

```text
1. 回滚前端构建产物
2. 回滚后端服务
3. 回滚 Worker
4. 数据库原则上不回滚，必要时恢复备份
```

## 6. 演示前 30 分钟巡检

```text
登录接口可用
工具列表可用
创建任务可用
Redis 无异常积压
Worker 在线
模型 Key 可用
后台任务列表可用
演示账号余额充足
```
