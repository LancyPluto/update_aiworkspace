# 08. 推荐代码结构与模块边界

本文用于统一 5 人开发时的代码组织方式。若现有项目已有结构，可保留现有结构，但模块边界建议按本文执行。

## 1. 推荐仓库结构

如果是一个仓库：

```text
ai-supermarket/
├── backend/                 # Spring Boot 后端
├── user-web/                # 用户端前端
├── admin-web/               # 管理后台前端
├── worker/                  # Python AI Worker
├── docs/                    # 文档
├── deploy/                  # 部署脚本、docker、nginx
├── sql/                     # 数据库脚本
└── README.md
```

如果现有项目不是这个结构，也至少保证：

```text
用户端、管理端、后端、Worker、SQL、部署文档相互独立。
```

## 2. 后端模块建议

```text
backend/
├── auth/                    # 用户/管理员登录鉴权
├── user/                    # 用户信息
├── tool/                    # 工具、分类、字段 Schema、Prompt
├── task/                    # 任务创建、状态机、结果查询
├── credit/                  # 算力账户、流水、冻结/扣除/释放
├── admin/                   # 管理端聚合接口
├── internal/                # Worker 内部接口
├── common/                  # 统一响应、错误码、异常、工具类
└── config/                  # 安全、Redis、数据库、跨域配置
```

## 3. 后端包边界


| 模块         | 可以依赖                       | 不应该做          |
| ---------- | -------------------------- | ------------- |
| `auth`     | `user`, `common`           | 不处理任务/算力业务    |
| `tool`     | `common`                   | 不直接创建任务       |
| `task`     | `tool`, `credit`, `common` | 不直接调用外部 AI 模型 |
| `credit`   | `common`                   | 不读取 Prompt    |
| `internal` | `task`                     | 不绕过任务状态机      |
| `admin`    | 业务模块服务                     | 不重复写业务逻辑      |

## 6. Worker 结构

```text
worker/
├── main.py                  # 启动入口
├── config.py                # 环境变量读取
├── queue/
│   └── redis_consumer.py
├── client/
│   ├── backend_client.py    # 调后端 internal 接口
│   └── model_client.py      # 调 AI 模型
├── prompt/
│   └── renderer.py          # Prompt 变量替换
├── handlers/
│   └── text_task_handler.py
└── logs/
```

## 7. 禁止跨边界操作

```text
前端不得写死 Prompt
前端不得写死工具字段
Worker 不直接扣算力
Worker 不直接把任务置 SUCCESS
后台不直接改数据库绕过接口
测试不手动改库伪造成功链路
```

## 8. 共享类型口径

建议所有端统一这些常量：

```text
TaskStatus
ToolStatus
UserStatus
CreditLogType
ApiErrorCode
```

至少在文档和代码中保持同名，不要出现一端 `PROCESSING`、另一端 `RUNNING`。
