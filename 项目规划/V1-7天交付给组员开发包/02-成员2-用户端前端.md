# 02. 成员 2：用户端前端

## 角色定位

你负责普通用户从登录到生成结果的完整体验。V1 不追求页面多，而是追求主链路稳定跑通。

## 必须交付页面

```text
登录/注册页
工具列表页
工具详情 + 动态表单页
任务等待/状态页
任务结果页
我的任务页
```

## 页面与接口

### 登录/注册页

接口：

```text
POST /api/v1/auth/register
POST /api/v1/auth/login
GET  /api/v1/users/me
```

要求：

```text
登录成功保存 token
接口 401 时跳转登录
注册成功后可直接登录或跳转登录
```

### 工具列表页

接口：

```text
GET /api/v1/tool-categories
GET /api/v1/tools
```

展示字段：

```text
toolCode
toolName
description
coverUrl
estimatedCreditCost
categoryName
```

### 工具详情 + 动态表单页

接口：

```text
GET /api/v1/tools/{toolCode}
POST /api/v1/tasks
```

动态字段类型本周只支持：

```text
text
textarea
select
number
```

提交任务请求：

```json
{
  "toolCode": "xiaohongshu_copywriting",
  "params": {
    "productName": "五一护理套餐",
    "targetCustomer": "年轻女性",
    "style": "种草"
  },
  "clientRequestId": "uuid-from-frontend"
}
```

要求：

```text
必填字段前端校验
提交按钮防重复点击
创建任务成功后跳转任务状态页
算力不足时提示用户
工具下架时提示不可用
```

### 任务等待/状态页

接口：

```text
GET /api/v1/tasks/{taskId}/status
GET /api/v1/tasks/{taskId}
```

V1 优先轮询：

```text
CREATED / QUEUED：每 3 秒
PROCESSING / RETRYING：每 5 秒
SUCCESS / FAILED / TIMEOUT / CANCELLED：停止轮询
```

展示：

```text
当前状态
progress
progressMessage
失败原因的用户友好文案
成功后展示结果
```

### 我的任务页

接口：

```text
GET /api/v1/tasks
GET /api/v1/tasks/{taskId}
```

展示：

```text
任务编号
工具名称
状态
创建时间
完成时间
进入详情按钮
```

## 统一前端状态文案

| 状态 | 文案 |
|---|---|
| `CREATED` | 任务已创建 |
| `QUEUED` | 排队中 |
| `PROCESSING` | AI 正在生成 |
| `RETRYING` | 生成遇到问题，正在重试 |
| `SUCCESS` | 生成完成 |
| `FAILED` | 生成失败 |
| `TIMEOUT` | 任务超时 |
| `CANCELLED` | 任务已取消 |

## 每日交付

| 日期 | 交付 |
|---|---|
| 第 1 天 | 路由、请求封装、登录页静态页面 |
| 第 2 天 | 登录联调、工具列表/详情页 |
| 第 3 天 | 动态表单渲染、创建任务联调 |
| 第 4 天 | 任务状态轮询、结果展示 |
| 第 5 天 | 我的任务页、错误态/空态 |
| 第 6 天 | 全链路联调修 Bug |
| 第 7 天 | 演示环境前端构建 |

## 不做

```text
支付页面
套餐页面
复杂个人中心
文件上传控件
收藏夹
SSE 必须项
```
