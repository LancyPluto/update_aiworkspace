# 15. 从 0 开始脚手架搭建方案

本项目没有现成框架，因此第 1 天不要急着写业务功能。必须先把 Spring Boot、Vue 用户端、Vue 管理后台、Python Worker、MySQL、Redis 的最小骨架搭起来。

## 1. 推荐技术栈

为了一周交付，选择成熟、资料多、团队容易协作的组合：


| 层      | 技术                          |
| ------ | --------------------------- |
| 后端     | Spring Boot 3.x             |
| Java   | JDK 17                      |
| 构建     | Maven                       |
| 数据库    | MySQL 8                     |
| 缓存/队列  | Redis                       |
| ORM    | MyBatis Plus 或 MyBatis      |
| 鉴权     | JWT                         |
| 用户端    | Vue 3 + Vite                |
| 管理后台   | Vue 3 + Vite + Element Plus |
| 前端状态   | Pinia                       |
| 前端请求   | Axios                       |
| Worker | Python 3.10+                |


## 2. 推荐仓库结构

从 0 开始建议使用一个仓库，便于 5 人一周内协作：

```text
ai-supermarket/
├── backend/
├── user-web/
├── admin-web/
├── worker/
├── sql/
├── deploy/
├── docs/
└── README.md
```

## 3. 第 1 天脚手架任务分配


| 成员  | 第 1 天必须完成                                           |
| --- | --------------------------------------------------- |
| 1 号 | 创建后端 Spring Boot 项目，连通 MySQL/Redis，提供 `/api/health` |
| 2 号 | 创建用户端 Vue 项目，完成路由、Axios 封装、登录页骨架                    |
| 3 号 | 创建 Python Worker，连通 Redis，能消费测试消息                   |
| 4 号 | 创建管理后台 Vue 项目，完成布局、路由、登录页骨架                         |
| 5 号 | 整理 `.env.example`、启动文档、初始化 SQL、测试健康检查               |

## 9. 第 1 天验收

必须全部通过：


## 10. 从 0 开始的关键原则

```text
第 1 天只搭骨架，不追求业务完整
第 2 天再做登录和工具
第 3 天必须打通任务入队
第 4 天必须打通 Worker 回写
第 5 天才补后台管理和异常流程
第 6 天只联调修 Bug
第 7 天只演示和验收
```
