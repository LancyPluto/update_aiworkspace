## 1. 你需要用到的分支约定（来自项目文档）

```text

```

## 2. 第一次连接仓库（两种情况）

### 2.1 你还没有代码：直接 clone（推荐）

把下面的 `<REPO_URL>` 换成 1 号给你的仓库地址（HTTPS 或 SSH 都行）。

```bash
git clone <REPO_URL>
cd <REPO_DIR>
git fetch --all --prune
```

然后拉取并切到 5 号分支：

```bash
git checkout -b feature/test-docs origin/feature/test-docs
```

如果远端还没有 `feature/test-docs`（常见于刚建仓库），你可以先从 `dev` 创建并推上去：

```bash
git checkout dev
git pull
git checkout -b feature/test-docs
git push -u origin feature/test-docs
```

### 2.2 你已经有代码文件夹：把它连接到远端仓库

在项目根目录执行：

```bash
git init
git remote add origin <REPO_URL>
git fetch --all --prune
```

然后拉取 `dev`（或你们当前主干分支）：

```bash
git checkout -b dev origin/dev
```

再创建/切换到 5 号分支：

```bash
git checkout -b feature/test-docs
git push -u origin feature/test-docs
```

## 3. 每天开始工作：同步 `dev` 与你的分支

你通常需要同时跟进 `dev` 的最新集成结果做回归，但自己的改动只放在 `feature/test-docs`。

```bash
git fetch --all --prune
git checkout dev
git pull
git checkout feature/test-docs
git pull
```

如果你需要把 `dev` 的最新改动合到你的分支（例如更新部署脚本、测试用例适配接口变更）：

```bash
git merge dev
```

> 约定提醒：接口/数据库契约变更必须按流程（群里说明 → 1 号确认 → 更新 `00-统一接口数据库契约.md` → 再改代码/文档）。
