# 04. 成员 4：管理后台

## 角色定位

你负责让管理员能配置工具、发布工具、查看任务。V1 后台不是完整运营系统，本周只做支撑主链路的最小后台。

## 必须交付页面

```text
后台登录页
工具列表页
新增/编辑工具页
字段配置页
Prompt 配置页
任务列表页
任务详情页
用户列表页
手动加算力弹窗
```

## 后台认证

接口：

```text
POST /api/admin/v1/auth/login
POST /api/admin/v1/auth/logout
GET  /api/admin/v1/auth/me
```

要求：

```text
未登录访问后台跳转登录
普通用户 token 不能访问后台
V1 只区分 ADMIN 和 USER
```

## 工具管理

接口：

```text
GET  /api/admin/v1/tools
POST /api/admin/v1/tools
PUT  /api/admin/v1/tools/{toolId}
POST /api/admin/v1/tools/{toolId}/publish
POST /api/admin/v1/tools/{toolId}/offline
```

工具字段：

```text
toolCode
toolName
categoryId
description
coverUrl
estimatedCreditCost
status: DRAFT / ONLINE / OFFLINE
```

发布前最小校验：

```text
工具基础信息完整
存在 ACTIVE 字段 Schema
存在 ACTIVE Prompt 版本
estimatedCreditCost >= 0
```

## 字段配置

接口：

```text
GET  /api/admin/v1/tools/{toolId}/field-schemas
POST /api/admin/v1/tools/{toolId}/field-schemas
POST /api/admin/v1/field-schemas/{schemaId}/publish
```

字段类型本周只支持：

```text
text
textarea
select
number
```

字段项：

```text
fieldKey
fieldName
fieldType
placeholder
required
optionsJson
sortOrder
```

## Prompt 配置

接口：

```text
GET  /api/admin/v1/tools/{toolId}/prompts
POST /api/admin/v1/tools/{toolId}/prompts
POST /api/admin/v1/prompts/{promptId}/versions
POST /api/admin/v1/prompt-versions/{promptVersionId}/test-generate
POST /api/admin/v1/prompt-versions/{promptVersionId}/publish
```

V1 只做：

```text
创建 Prompt 草稿
测试生成
发布 Prompt
查看当前 ACTIVE Prompt
```

V1 不做复杂回滚，只允许新建版本后发布。

## 任务管理

接口：

```text
GET /api/admin/v1/tasks
GET /api/admin/v1/tasks/{taskId}
```

列表展示：

```text
taskId
taskNo
用户昵称
工具名称
状态
消耗算力
错误码
创建时间
完成时间
```

详情展示：

```text
任务基础信息
用户输入参数
生成结果
失败原因
任务日志
算力流水
```

## 用户与算力

接口：

```text
GET  /api/admin/v1/users
POST /api/admin/v1/users/{userId}/credits/manual-add
```

V1 只做手动加算力，不做审批。

## 每日交付


| 日期    | 交付               |
| ----- | ---------------- |
| 第 1 天 | 后台路由、登录页、布局      |
| 第 2 天 | 工具列表、新增/编辑工具     |
| 第 3 天 | 字段配置、Prompt 配置   |
| 第 4 天 | 发布工具、测试生成        |
| 第 5 天 | 任务列表/详情、用户列表、加算力 |
| 第 6 天 | 联调修 Bug          |
| 第 7 天 | 后台演示数据验证         |


## 不做

```text
订单管理
套餐管理
算力审批
复杂权限矩阵
操作日志独立页面
监控看板
Worker 状态页面
系统配置页面
```
