# 09. 环境变量与本地启动清单

本文用于统一每个成员的本地环境，避免“我这里能跑，你那里不能跑”。

## 1. 必需服务

```text
MySQL
Redis
后端 Spring Boot
用户端前端
管理后台前端
Python Worker
```

本机演示建议：

```text
MySQL 和 Redis 用 Docker Compose 启动
后端、用户端、管理后台、Worker 开发期本地启动
第 7 天如时间允许，再把后端和 Worker 放进 Docker Compose
```

## 2. 后端环境变量

```env
SERVER_PORT=8080

MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DATABASE=ai_supermarket_v1
MYSQL_USERNAME=root
MYSQL_PASSWORD=your_password

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=
REDIS_DATABASE=0

JWT_SECRET=replace-with-local-secret
JWT_EXPIRE_MINUTES=1440

AI_TASK_QUEUE=ai:task:queue
INTERNAL_API_TOKEN=replace-with-internal-token

MODEL_PROVIDER=deepseek
MODEL_API_BASE_URL=https://api.deepseek.com
MODEL_API_KEY=replace-with-model-key
MODEL_NAME=deepseek-chat
```

## 3. 用户端前端环境变量

```env
VITE_API_BASE_URL=http://localhost:8080
VITE_APP_NAME=AI超市平台
```

## 4. 管理后台环境变量

```env
VITE_ADMIN_API_BASE_URL=http://localhost:8080
VITE_ADMIN_APP_NAME=AI超市管理后台
```

## 5. Worker 环境变量

```env
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=
REDIS_DATABASE=0
AI_TASK_QUEUE=ai:task:queue

BACKEND_INTERNAL_BASE_URL=http://localhost:8080
INTERNAL_API_TOKEN=replace-with-internal-token

MODEL_PROVIDER=deepseek
MODEL_API_BASE_URL=https://api.deepseek.com
MODEL_API_KEY=replace-with-model-key
MODEL_NAME=deepseek-chat
```

## 6. 本地启动顺序

```text
1. docker compose 启动 MySQL 和 Redis
2. 执行 07-V1数据库初始化草案.sql
4. 启动后端
5. 启动 Worker
6. 启动用户端前端
7. 启动管理后台前端
```

## 7. 本地自检

```text
后端健康检查正常
Redis 能连接
Worker 启动后无报错
管理员能登录后台
用户能登录用户端
后台能创建工具
用户端能看到工具
创建任务后 Redis 队列有消息
Worker 能消费并回写结果
```

## 8. 敏感信息规则

```text
模型 Key 不提交 Git
JWT_SECRET 不提交 Git
数据库密码不提交 Git
.env.local 不提交 Git
只提交 .env.example
```
