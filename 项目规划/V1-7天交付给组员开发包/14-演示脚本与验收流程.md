# 14. 演示脚本与验收流程

本文用于第 7 天最终演示。演示时按固定路线走，避免现场临时点未完成页面。

## 1. 演示前准备

```text
管理员账号可登录
普通用户账号可登录
测试工具已配置
测试用户算力余额 >= 50
Worker 已启动
Redis 正常
模型 Key 正常
```

## 2. 演示路线

### 第一段：后台配置工具

```text
1. 管理员登录后台
2. 进入工具管理
3. 查看小红书文案生成工具
4. 查看字段配置
5. 查看 Prompt 配置
6. 发布工具或确认工具已上线
```

证明点：

```text
工具不是前端写死
字段可以后台配置
Prompt 可以后台维护
```

### 第二段：用户创建任务

```text
1. 用户登录
2. 进入工具列表
3. 打开小红书文案生成
4. 填写产品名称、目标用户、风格
5. 点击生成
6. 进入任务状态页
```

证明点：

```text
用户端能读取后台发布工具
动态表单可用
任务能创建
```

### 第三段：Worker 执行并返回结果

```text
1. 展示任务状态从 QUEUED 到 PROCESSING
2. 等待 Worker 完成
3. 展示 SUCCESS 和生成结果
4. 进入我的任务查看历史记录
```

证明点：

```text
异步队列可用
Worker 可用
结果保存可查询
```

### 第四段：后台追踪任务

```text
1. 管理员进入任务列表
2. 找到刚才的任务
3. 打开任务详情
4. 查看输入参数、状态、结果、失败原因或日志
```

证明点：

```text
后台可追踪
运营能排查问题
```

## 3. 异常演示可选项

如果时间允许，可演示：

```text
算力不足不能创建任务
工具下架后用户端不可用
普通用户不能访问后台
模型失败后任务变 FAILED
```

## 4. 验收口径

必须通过：

```text
用户能登录
管理员能登录
管理员能配置并发布工具
用户能看到工具
用户能创建任务
Worker 能执行任务
用户能看到结果
后台能看到任务
```

## 5. 不要演示

```text
订单
套餐
支付
审批
复杂权限
监控告警
文件上传
多模态
```
