# 16. 一周从 0 开发排期修正版

因为项目没有现成框架，一周内不能按“完整企业级 V1”推进，只能交付“最小演示可用 V1”。本排期以 Spring Boot + Vue 从 0 搭建为前提。

## 总体判断


| 目标        | 一周可行性    |
| --------- | -------- |
| 完整企业级 V1  | 不可行      |
| 可内部试用 V1  | 勉强可行，风险高 |
| 可演示主链路 V1 | 可行       |


本周目标应锁定为：

```text
可演示主链路 V1
```

## 第 1 天：搭骨架

目标：

```text
所有项目能启动，基础服务能互通。
```

交付：

```text
backend Spring Boot 项目
user-web Vue 项目
admin-web Vue 项目
worker Python 项目
MySQL 初始化脚本
Redis 连接
/api/health
```

当天禁止：

```text
写复杂页面
写复杂权限
写订单/套餐/审批
讨论非 V1 功能
```

## 第 2 天：登录 + 工具展示

目标：

```text
管理员能登录，用户能登录，后台能创建工具，用户端能看到工具。
```

交付：

```text
用户登录
管理员登录
工具分类
工具列表
工具详情
后台工具新增/编辑
```

## 第 3 天：动态字段 + 创建任务

目标：

```text
后台配置字段，用户端动态渲染表单，用户能创建任务。
```

交付：

```text
字段 Schema 创建
字段 Schema 发布
工具发布
动态表单
创建任务接口
算力冻结
Redis 入队
```

## 第 4 天：Worker 执行 + 结果回写

目标：

```text
Worker 能消费任务、调用 AI、回写成功结果。
```

交付：

```text
Worker 消费 Redis
execution-context 接口
processing 回写
success 回写
failed 回写
结果保存
用户任务详情
```

## 第 5 天：后台追踪 + 算力简化

目标：

```text
后台能查任务，用户能看历史，算力能对上。
```

交付：

```text
后台任务列表
后台任务详情
用户我的任务
算力账户查询
手动加算力
失败释放算力
重复成功不重复扣费
```

## 第 6 天：联调修 Bug

目标：

```text
主链路稳定，异常流程可控。
```

只做：

```text
登录失败
权限失败
工具下架
算力不足
任务失败
重复提交
重复回写
用户不能看别人的任务
```

不做：

```text
新增大功能
重构架构
新增页面
修改数据库主结构
```

## 第 7 天：部署 + 演示

目标：

```text
演示环境稳定跑通。
```

交付：

```text
部署环境
演示账号
演示工具
演示脚本
验收报告
README
```

## 每天晚上必须跑的主链路

```text
管理员登录
→ 创建/确认工具
→ 发布工具
→ 用户登录
→ 用户看到工具
→ 用户提交任务
→ Worker 执行
→ 用户看到结果
→ 后台看到任务
```

## 从 0 开始后的范围再压缩

必须保留：

```text
登录
工具配置
动态表单
Prompt 配置
任务创建
Redis 队列
Worker 执行
结果查询
后台任务查看
算力固定扣减
```

可以砍掉：

```text
注册页面，可先用初始化用户
SSE，可先轮询
用户端算力流水，可先只查余额
后台用户禁用，可后置
Prompt 回滚，可后置
任务取消，可后置
任务重新生成，可后置
```

## 第 3 天检查点

如果第 3 天结束还没有完成：

```text
用户创建任务
任务进入 Redis
```

则必须继续砍范围：

```text
砍后台字段配置，改为种子数据初始化字段
砍后台 Prompt 配置，改为种子数据初始化 Prompt
只保留后台任务查看
```

## 第 5 天检查点

如果第 5 天结束还没有完成：

```text
Worker 成功回写结果
```

则最终演示改为：

```text
后端 mock AI 结果
Worker 作为可选演示
```

但必须在验收报告中注明 Worker 未完全完成。
